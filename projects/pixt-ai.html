03

Editor

SCENE BASED EDITING

Scene 단위로 콘텐츠를 구성하고 편집

Pixt AI의 Editor는 하나의 영상을 여러 Scene으로 나누어 관리합니다. 각 Scene에는 콘텐츠, TTS, BGM, Subtitle, Transition 등의 정보가 연결되고, 이 데이터가 Preview Player의 Clip으로 변환됩니다.

  • 영상 / 이미지 콘텐츠 선택
  • Scene별 재생 시간 관리
  • TTS 및 BGM 설정
  • 자막 스타일 및 내용 편집
  • Scene Transition 설정

01

공통 시간축

Scene의 startTime과 duration을 기준으로 각 Clip의 재생 구간을 계산하여 하나의 시간축 위에 배치합니다.

02

Current Time

Player의 currentTime을 기준으로 등록된 Clip이 자신의 상태에 맞게 seek / play / pause하도록 구성되어 있습니다.

03

Media Control

Video와 Audio는 각각의 media resource를 사용하지만 Player의 공통 playback state와 volume, muted, playbackRate를 공유합니다.

06

Technical Points

01

Video Loop 처리

Scene보다 원본 영상이 짧고 loop가 활성화된 경우 필요한 길이만큼 VideoClip을 여러 개 생성하고 Group Clip으로 묶어 재생 구간을 채웁니다.

02

Trim & Object Fit

원본 영상의 trim start/end를 유지하면서 Scene의 재생 시간에 맞추고, Fit Cover / Contain 효과를 통해 화면 비율에 맞게 렌더링합니다.

03

Transition

Scene 사이의 transition duration만큼 시간축을 조정한 뒤 이전 Clip과 다음 Clip을 연결해 자연스러운 장면 전환을 구성합니다.

04

Render Texture Group

여러 ViewClip을 Container에 묶고 RenderTexture로 렌더링하여 하나의 View처럼 다룰 수 있도록 Group Clip 구조를 사용합니다.

08

Retrospective

UI를 만드는 것에서 미디어 재생 구조를 이해하는 개발로

Pixt AI에서는 일반적인 웹 UI뿐 아니라 영상·이미지·음원·자막을 동일한 시간축에서 다루는 기능을 구현했습니다. 특히 Editor의 Scene 데이터를 Preview Player의 Clip 구조로 변환하는 과정을 통해 UI와 실제 미디어 렌더링 사이의 데이터 흐름을 이해하고, 복잡한 기능을 컴포넌트와 데이터 단위로 나누어 설계하는 경험을 얻었습니다.
